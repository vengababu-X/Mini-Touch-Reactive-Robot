🎞️ What happens when you touch it?

😴 Idle  
   │  
   ├─ 👆 Tap once  
   │     └─ 🗣️ "Hello. I am Max."  
   │  
   ├─ 👆👆 Double tap  
   │     └─ 😐 "Please do not do that."  
   │  
   ├─ 👆👆👆 Spam tap  
   │     └─ 😖 "That is hurting me."  
   │  
   └─ ✋ Long press  
         └─ 🙂 "Hey… be gentle."

While Max speaks:

👄 Mouth animates  
✋ Both hands appear & wave  
🔊 Voice plays smoothly  

When Max stops:

🛑 Mouth stops  
🫥 Hands disappear  
😌 Back to idle

🧠 How Max Thinks (Very Simple, Very Stable)

Max doesn’t “think” — Max reacts.

Touch ➜ Decide ➜ Speak ➜ Animate ➜ Stop ➜ Idle  

That’s it.  
No background listeners.  
No fragile magic.

This is why it actually works.

⚠️ Important Notes (Read Once)

• Touch works best with clear, intentional taps  
• Speech requires user interaction (browser security rule)  
• This is a touch-reactive demo, not a voice assistant  
• Designed for stability, not tricks
